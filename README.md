# Neural Network for replacing Fourier-Mellin Transforms
## What is this project?
This is a side project i made in the span of 2 days, which aims to beat the effieciency of Fourier-Mellin Transforms 
(more on those [here](https://sthoduka.github.io/imreg_fmt/docs/fourier-mellin-transform/)) using a neural network programmed by me in c# and optimised with the ILGPU library.
## How to use it
After compiling the code with .NET according to their [official instructions](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-build) the program should guide you through all the inputs, however i reccomend reading through the code and using it more as a library than standalone app.
## The coding process
All of the c# code was written by me (no copy/paste from claude or any other LLM's, although i did used claude in the process, just not for ready code) in 3 sessions, all described in the commits (the time written down in the commits is time tracked by Hackatime, not the actual time i spent on those sections).
